# Prudent Financial Services, Inc. (Prufininc) - Vue.js Edition
### Production Accounting, 247Bookkeeper™ & 247eCabinet™ Platform

A modern, high-performance web platform built with **Vue 3 (Composition API)**, **Vue Router**, and **Vite** for **Prudent Financial Services, Inc. (Prufininc)** — mirroring the exact business aim, services, and navigation structure of `https://www.prufininc.com/`.

---

## ⚡ Quick Start & Development

```bash
# 1. Run local development server with Hot Module Replacement (HMR)
npm run dev

# 2. Build optimized production bundle
npm run build

# 3. Preview production build locally (Node server)
npm start
```

---

## 🚀 Vue.js Architecture

* **Framework:** Vue 3 (`<script setup>`, Composition API)
* **Build Tool:** Vite 8 (sub-second HMR and lightning builds)
* **Router:** Vue Router (HTML5 History Mode, smooth anchor scrolling, `.html` backward-compatible aliases)
* **Styling:** Tailwind CSS + Custom CSS (`Plus Jakarta Sans` & `Inter`)

### Page & Route Map
* **`/`** — [HomeView.vue](src/views/HomeView.vue): Hero, KPI preview dashboard, "Welcome to Prudent!", Tech Advantage, Industries grid, on-page Lead Form, and Big CTA.
* **`/about`** — [AboutView.vue](src/views/AboutView.vue): Company heritage, 20-year track record, dual-shore delivery model, leadership.
* **`/outsourcing`** — [OutsourcingView.vue](src/views/OutsourcingView.vue): In-house vs. outsourced comparison, GL/AP/AR/payroll workflows, bank-grade security, interactive savings calculator, FAQ.
* **`/services`** — [ServicesView.vue](src/views/ServicesView.vue): Core bookkeeping, financial analysis, payroll, taxation, IT consulting.
* **`/consulting`** — [ConsultingView.vue](src/views/ConsultingView.vue): Financial analysis, 13-week cash flow budgeting, QuickBooks & software consulting, M&A due diligence, Virtual CFO.
* **`/pricing`** — [PricingView.vue](src/views/PricingView.vue): Predictable monthly tiers (Starter, Growth, Controller), ROI calculator.
* **`/contact`** — [ContactView.vue](src/views/ContactView.vue): Interactive inquiry form, Forest Hills NY & Hyderabad offices, phone/email.
* **`/247bookkeeper`** — [BookkeeperView.vue](src/views/BookkeeperView.vue): 247Bookkeeper™ live portal demo with KPI cards, AP approval queue, transactions ledger.
* **`/247ecabinet`** — [ECabinetView.vue](src/views/ECabinetView.vue): 247eCabinet™ live document vault demo with folder navigation, search, and document uploads.
* **`/how-it-works`** — [HowItWorksView.vue](src/views/HowItWorksView.vue): 4-step onboarding and overnight dual-shore lifecycle.
* **`/industries`** — [IndustriesView.vue](src/views/IndustriesView.vue): Specialized accounting for Healthcare, E-Commerce, Legal, Construction, Tech, Wholesale.
